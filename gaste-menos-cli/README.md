# Gaste Menos CLI

Aplicação em linha de comando (CLI) para controle simples de gastos pessoais.

---

## Problema

Muitas pessoas não possuem controle financeiro básico, o que leva a gastos desnecessários, desorganização e dificuldade para economizar dinheiro.

---

## Solução

O Gaste Menos CLI permite registrar e acompanhar gastos de forma simples, ajudando o usuário a visualizar seus hábitos financeiros e manter controle sobre seu dinheiro.

---

## Público-alvo

* Estudantes
* Jovens adultos
* Pessoas que desejam melhorar o controle financeiro

---

## Funcionalidades

* Adicionar gasto (descrição e valor)
* Listar gastos
* Remover gasto
* Calcular total gasto
* Definir limite de gastos
* Alertar ao ultrapassar o limite

---

## Tecnologias

* Python
* Pytest (testes automatizados)
* Ruff (linting)
* GitHub Actions (CI)

---

## Instalação

```bash
git clone <repositorio>
cd gaste-menos-cli
pip install -r requirements.txt
```

---

## Execução

```bash
python src/main.py
```

---

## Testes

```bash
pytest
```

---

## Lint

```bash
ruff check .
```

---

## Integração Contínua (CI)

O projeto utiliza GitHub Actions para executar automaticamente:

* lint (ruff)
* testes (pytest)
