
#  Gaste Menos CLI

Aplicação de linha de comando para controle de gastos pessoais.

##  Nova funcionalidade

Integração com API pública de cotação de moedas utilizando AwesomeAPI.

Agora o sistema consegue:
- Consultar cotação do dólar em tempo real
- Converter o total de gastos para USD
- Validar integração com teste automatizado

##  Tecnologias
- Python
- Requests
- Pytest
- GitHub Actions

##  Como executar

Clone o projeto:

```bash
git clone https://github.com/seu-usuario/gaste-menos-cli.git
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python src/main.py
```

## 🧪 Rodar testes

```bash
pytest
```

## 🌎 API utilizada
